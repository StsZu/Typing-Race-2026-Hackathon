# 4. Специфікація: «Багатомовна версія сайту Typing Race 2026»

Статус: уточнена; відкритих питань немає. Конституція: `task/constitution.md`.

## Що і навіщо

Головна сторінка доступна українською, англійською й польською за окремими адресами з однаковими функціями. Закриває проблему з `task/idea.md`: людина без української може пройти весь шлях — від заголовка до результату тесту — своєю мовою. Перший крок — узгодити термінологію українського оригіналу, щоб помилка не перейшла в переклади.

## Користувацькі сценарії

- **US1 (P1) — Узгоджений український оригінал.** Відвідувач бачить «сенсорний друк» у заголовках і описі сторінки; пошуковик і соцмережі показують той самий термін.
- **US2 (P1) — Англомовний учень.** Відкриває `en/`, бачить QWERTY, проходить тест і отримує результат англійською; після будь-якої дії українські рядки не з'являються.
- **US3 (P2) — Польськомовний учень.** Відкриває `pl/`, бачить польську схему з літерами діакритики, тест польською, результати з правильними формами множини.
- **US4 (P2) — Перемикання мови.** Користувач змінює мову в шапці; тема й календар практики зберігаються; активна спроба тесту не зникає без попередження.
- **US5 (P3) — Змішані налаштування.** Англомовний інтерфейс з українською вправою й розкладкою ЙЦУКЕН.

## Функціональні вимоги

- **FR-01** Український оригінал використовує «сенсорний друк» і не містить «наосліп» / «сліпий друк» у видимому тексті й метаданих.
- **FR-02** Існують три мовні адреси `./`, `en/`, `pl/`; кожна має власну мову документа, взаємні посилання на відповідники й canonical на себе.
- **FR-03** У шапці є перемикач «Українська · English · Polski» з назвами мов, позначенням активної, доступом з клавіатури й видимим фокусом.
- **FR-04** Мова інтерфейсу, мова вправи й розкладка — незалежні налаштування.
- **FR-05** Усі тексти інтерфейсу, включно з тими, що з'являються після дій (підказки клавіш, результати, калькулятор, календар, плеєр, повідомлення про помилки сховища й каталогу), показуються мовою сторінки.
- **FR-06** Підписи частин пісень («Вступ», «Приспів»…) перекладаються й мають мову інтерфейсу; слова пісень не змінюються.
- **FR-07** Клавіатура першого екрана відповідає мові сторінки; польська схема може показати шар літер `ą ć ę ł ń ó ś ź ż`.
- **FR-08** Для кожної мови вправи є власний текст тесту; його метрики (середня довжина слова, частка великих літер, пунктуації, символів із модифікатором) задокументовано.
- **FR-09** Картки тренажерів показують опис і переваги мовою сторінки; назви й автори — без змін.
- **FR-10** Зміна мови не очищує тему й календар практики.
- **FR-11** Зміна українського тексту автоматично позначає відповідні переклади як застарілі.
- **FR-12** Числа з одиницями («днів», «dni», “days”) мають правильну форму множини для кожної мови.

## Межа першого релізу

| Блок сторінки | Перекладається | Лишається мовою оригіналу |
|---|---|---|
| Шапка, навігація, герой, метадані | так | — |
| Інтерактивна клавіатура, калькулятор, тест | так | — |
| Картки тренажерів | опис, переваги, `alt` | назва, автор, URL |
| План на 30 днів | так | — |
| Музика | керування, пояснення, підписи частин | назви пісень, слова |
| Про хакатон, фінальний заклик, футер | так | — |

## Критерії успіху

- **SC-01** `grep -c -E 'наосліп|сліпий друк|сліпого друку'` по `index.html` дає 0; те саме для `en/`, `pl/`, `locales/` разом із `blind typing|pisanie na ślepo`.
- **SC-02** На `en/` і `pl/` після сценарію взаємодії (клавіші схеми, калькулятор, повний тест, позначення дня, перемикання пісні) — 0 кириличних символів поза елементами з `lang="uk"`.
- **SC-03** Перевірка словників: 100 % ключів, збіг параметрів, 0 порожніх значень, 0 непереглянутих застарілих ключів.
- **SC-04** Три адреси відкриваються напряму з кореня й з підкаталогу; 0 відповідей 404 для локальних ресурсів.
- **SC-05** Ширина 360 px: 0 горизонтальної прокрутки; під псевдолокаллю жоден підпис кнопки не обрізаний.
- **SC-06** Українська сторінка після змін: ті самі ключі `localStorage`; той самий результат тесту на тому самому введенні; `git diff` змінює лише заплановані фрагменти.
- **SC-07** `check-links.mjs` — 0 нових битих посилань; `check-repository.mjs` проходить на чистому експорті.
- **SC-08** Перемикач мови досяжний клавішею Tab, активується Enter/Space, активна мова позначена для програм читання з екрана.
- **SC-09** Форми для 1, 2, 5, 22 днів правильні для uk, en, pl.
- **SC-10** 0 помилок консолі на кожній мовній сторінці.

## Не входить до проєкту

- Повний переклад `hackathon.html` (на цьому етапі — лише коротке резюме, окрема хвиля після релізу).
- Переклад `docs/`, `dictionaries/`, `rules_for_hacathon/`, описів учасників у `sites/`.
- Переклад слів пісень; переклад зовнішніх тренажерів.
- Польська мініпрактика й польський частотний словник.
- Міграція ключів `localStorage` на новий префікс.
- Машинний переклад під час відкриття сторінки.
- Публікація й деплой.
