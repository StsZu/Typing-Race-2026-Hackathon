# Конституція проєкту «Багатомовна версія сайту Typing Race 2026»

Постійні правила для перекладу головної сторінки на English і Polski. Порушення будь-якого пункту розділу **Non-negotiables** блокує приймання результату.

Джерела: `task/multilingual-site-ideas-claude.md`, `idea/multilingual-site-proposal.md`, `AGENTS.md` репозиторію.

## I. Принципи

1. **Українська сторінка — джерело.** `index.html` лишається оригіналом і редагується вручну. `en/index.html` і `pl/index.html` генеруються з нього та словників; вручну їх не правлять.
2. **Статичний сайт без нових залежностей.** Жодних фреймворків, CDN чи сервісів перекладу під час відкриття сторінки. Скрипти — Node.js з вбудованими модулями, як решта `scripts/`.
3. **Одна термінологія.** У текстах інтерфейсу — «сенсорний друк» / «сенсорний набір», “touch typing”, “pisanie bezwzrokowe”. «Наосліп», «сліпий друк» та їхні відповідники не вживаються.
4. **Оригінальний контент мовою оригіналу.** Слова пісень, навчальні корпуси, назви тренажерів, імена авторів, тексти учасників у `sites/` не перекладаються й не редагуються.
5. **Доказ, а не думка.** Кожне завдання закривається командою або артефактом у `task/evidence/`.

## II. Обмеження

- Сайт має працювати як у корені домену, так і в підкаталозі GitHub Pages.
- Компактне форматування кореневих `index.html`, `app.js`, `style.css` зберігається; жодного переформатування поза зміненими фрагментами.
- `dictionaries/` не змінюється в межах цього проєкту.
- Зміна ключів `localStorage`, схеми `catalog.json` чи публічних адрес — лише після окремого погодження.
- Коміт, push, публікація — окрема дія після погодження користувача.

## III. Пріоритети (при конфлікті — вищий виграє)

1. Чинна українська версія не ламається й поводиться як раніше.
2. Коректна термінологія та мова кожної версії.
3. Доступність: клавіатура, `lang`, програми читання з екрана.
4. Повнота перекладу інтерфейсу.
5. Швидкість впровадження.

## IV. Стандарти якості

| Область | Стандарт |
|---|---|
| Термінологія | 0 входжень `наосліп`, `сліпий друк`, `сліпого друку`, `blind typing`, `pisanie na ślepo` у `index.html`, `en/`, `pl/`, `locales/` |
| Посилання | `node scripts/check-links.mjs` — 0 нових битих посилань (базова лінія 29.10.2026: 3 у `rules_for_hacathon/old/`) |
| Репозиторій | `node scripts/check-repository.mjs` на чистому експорті відстежуваних файлів — без нових причин падіння (базова лінія 29.10.2026: застаріле позначення в `sites/site-5-typing-race-2026.md`; у робочій теці ще й `.DS_Store`, див. `alignment.md`) |
| Словники | 100 % ключів української основи присутні в `en` і `pl`; параметри збігаються; 0 порожніх значень |
| Витоки | 0 кириличних символів на `en/` і `pl/` поза елементами з `lang="uk"` — у HTML і в DOM після сценарію взаємодії |
| Верстка | Ширина 360 px: без горизонтальної прокрутки; під псевдолокаллю (+40 %) жоден підпис кнопки не обрізаний |
| Консоль | 0 помилок у консолі на кожній мовній сторінці |
| Теми | Світла й темна перевірені на кожній мовній сторінці |
| Обсяг змін | `git diff` кожного завдання торкається лише файлів і фрагментів, названих у завданні |

## V. Non-negotiables

1. Українська сторінка зберігає поведінку: ті самі ключі сховища, тест, календар, плеєр.
2. Жодного «наосліп» / «сліпий друк» у текстах інтерфейсу будь-якої мови.
3. Генеровані сторінки не редагуються вручну.
4. Слова пісень і тексти учасників не змінюються.
5. Нічого не публікується й не пушиться без окремого погодження.

## VI. Процес

- Кожне завдання має перевірний результат і умову завершення; оркестратор перевіряє до переходу далі.
- Не більше 3 ітерацій виправлень на одне завдання; далі — фіксуємо відхилення в `task/alignment.md` і рухаємося.
- Докази перевірок складаються в `task/evidence/`.
