# 1. Ідея

## Формулювання (одним реченням)

Англомовні та польськомовні відвідувачі отримують головну сторінку Typing Race 2026 своєю мовою, щоб почати вчитися сенсорного друку без перекладача.

| | |
|---|---|
| **Проблема** | Сайт повністю українською, тож людина без української не розуміє ні пояснень, ні результатів тесту, хоча схеми EN і PL та англійські й польські пісні вже є. |
| **Для кого** | Англомовні й польськомовні учні та викладачі; україномовні, які тренують польську чи англійську. |
| **Бажана зміна** | Три мовні адреси (`./`, `en/`, `pl/`), перемикач мови, інтерфейс без українських «латок» після взаємодії. |
| **Користь** | Ширша аудиторія хакатону без окремого сайту; одна кодова база; посилання одразу потрібною мовою. |

## Вхідні матеріали

- `index.html` — 35,5 КБ в 11 рядках; ≈157 текстових вузлів із кирилицею (без шаблонів пісень) і 13 атрибутів (`alt`, `aria-label`, `content`); 5 `<template>` із піснями.
- `app.js` — 14,5 КБ у 32 рядках; ≈52 рядкові літерали з кирилицею (підказки, результати, календар, плеєр).
- `catalog.json` (83 рядки, 5 тренажерів) і `catalog.js` (5,1 КБ, `window.TRAINERS`) — описи та переваги українською.
- `idea/multilingual-site-proposal.md` — основна пропозиція (архітектура, глосарій, порядок, критерії).
- `task/multilingual-site-ideas-claude.md` — доповнення: термінологія, підписи пісень, шар AltGr, перевірки, актуальність перекладів.
- Чинні перевірки: `scripts/check-links.mjs`, `scripts/check-repository.mjs`.

# 2. Оцінювання

## За
- Схеми клавіатур `uk`/`en`/`pl` і багатомовні пісні вже є — бракує лише перекладу інтерфейсу.
- Сайт статичний: мовні сторінки — це файли, без серверної логіки.
- Українська основа лишається джерелом, тож ризик зламати чинний сайт малий.

## Проти / витрати
- Рядки в `app.js` записані прямо в коді — їх треба винести без зміни поведінки.
- Потрібні два нові скрипти (генерація, перевірка) і словники на ≈220 ключів.
- Польська редактура носієм мови — зовнішня залежність.

## Ризики

| Ризик | Вплив | Пом'якшення |
|---|---|---|
| Зламати українську сторінку під час розмітки рядків | Високий | Пріоритет 1 конституції; порівняння поведінки до/після (SC-06) |
| Неперекладені динамічні рядки | Середній | Перевірка DOM після сценарію взаємодії (SC-02) |
| Переклади застарівають після змін українського тексту | Середній | Відбиток джерела в словниках, звіт про застарілі ключі |
| Невизначений основний домен для `hreflang`/canonical | Середній | Уточнення C6 — блокує хвилю 4 |
| Польський переклад без редактури | Середній | Чернетка позначається, приймання — після редактора |

## Альтернативи
- Заміна текстів JavaScript на одній сторінці — відкинуто: одна мова в HTML, погані метадані й посилання.
- Три ручні копії — відкинуто: розсинхронізація після кожної правки.
- Спільний шаблон для всіх трьох мов — відкладено: доречний, коли сторінок стане більше.
