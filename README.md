# Typing Race 2026 Hackathon

Стартовий репозиторій хакатону програм-тренажерів сенсорного набору українською та англійською мовами.

Мета — створити не просто тест швидкості, а послідовну навчальну систему: правильний палець для кожної клавіші, стабільне положення рук, робота без погляду на клавіатуру, точність і лише потім швидкість.

Суперприз: 10 000 грн та представлення найкращого рішення в підрозділах.

[Відкрити сторінку хакатону](index.html) · [Прочитати технічне завдання](docs/TECHNICAL_SPECIFICATION.md) · [Переглянути словники](dictionaries/README.md)

## Що треба створити

Браузерний тренажер із трьома рівнями навчання:

1. Клавіатурні гами — послідовності клавіш, домашній ряд, окремі пальці та рухи між рядами.
2. Слова — вправи лише з уже вивчених клавіш, без екранної підказки під час залікової спроби.
3. Швидкість — частотні біграми, триграми, словосполучення та тексти в розділі Академія.

Повні функціональні вимоги та система оцінювання на 100 балів наведені в [технічному завданні](docs/TECHNICAL_SPECIFICATION.md).

## Швидкий старт

~~~bash
python3 -m http.server 8000
~~~

Після запуску відкрийте http://localhost:8000.

Перевірки репозиторію:

~~~bash
./scripts/verify-data.sh
node scripts/check-links.mjs
node scripts/check-repository.mjs
~~~

## Участь

Правила подання роботи: [docs/PARTICIPATION.md](docs/PARTICIPATION.md).

Перед стартом організатор заповнює:

- строк подання робіт: [дата і час];
- склад журі: [ПІБ та ролі];
- форма або канал подання: [посилання];
- контакт для запитань: [контакт].

## Дані та ліцензії

Кожен набір має власні умови. Походження й статус наведені в [маніфесті](dictionaries/manifest.yml) і [політиці даних](docs/DATA_POLICY.md). Відсутність ліцензії означає, що умови повторного поширення визначає організатор; це не перетворює матеріал на відкриті дані.

Контрольні суми охоплюють усі файли в каталозі dictionaries, крім самого файлу контрольних сум.
