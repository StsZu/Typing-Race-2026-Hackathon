# Готовність до GitHub

Статус: технічно готово, потрібні організаційні рішення.

## Виконано

- проста структура папок;
- статична сторінка без build-кроку;
- відносні посилання для GitHub Pages;
- локальні CSS і JavaScript без CDN;
- словники розділені за мовою та типом;
- додані маніфест і SHA-256;
- додані автоматичні перевірки;
- службові файли винесені з публічної структури;
- секрети та локальний архів виключені через gitignore;
- TT не виключений через gitignore.

## Перед публікацією

1. Заповнити строки, журі, контакт і канал подання.
2. Визначити ліцензію власного HTML, CSS, JavaScript і документації.
3. Підтвердити режим використання наборів зі статусом REVIEW_REQUIRED.
4. Додати віддалений репозиторій.
5. Увімкнути GitHub Pages із кореня основної гілки.

Коміт, push і deploy у межах підготовки не виконувалися.
