# Каталог словників

Матеріали розділено спочатку за мовою, а потім за тим, як вони використовуються у тренажері.

~~~text
dictionaries/
├── ukrainian/
│   ├── wordlists/   # слова, частоти та Hunspell
│   ├── academy/     # структурована програма вправ
│   ├── tutor/       # курси й уроки сенсорного набору
│   ├── knowledge/   # тематичні навчальні тексти
│   ├── texts/       # додаткові українські тексти
│   ├── reference/   # довідкові матеріали, не вправи
│   └── downloads/   # готові ZIP-пакети
├── english/
│   ├── wordlists/
│   ├── academy/
│   ├── tutor/
│   ├── knowledge/
│   ├── reference/
│   └── downloads/
├── index.html       # сторінка завантаження
├── manifest.yml     # джерела, ліцензії та склад
└── CHECKSUMS.sha256
~~~

## Що обрати

| Категорія | Для чого вона потрібна | Основні формати |
|---|---|---|
| `wordlists` | добір слів за частотою, довжиною та відкритими клавішами | TXT, DIC, AFF |
| `academy` | послідовні вправи від домашнього ряду до швидкості | JSON, TS |
| `tutor` | готові уроки та курси сенсорного набору | JSON, Markdown |
| `knowledge` | тренування на тематичних навчальних текстах | Markdown |
| `texts` | додаткові тексти й диктанти; є лише для української | TXT |
| `reference` | словники інтерфейсу й інші довідкові файли | TS |

Для нового застосунку найпростіше почати з `academy/typing-race-2026/course.json` і `tutor/tt-exercises/all-exercises.json`. Це готові структуровані JSON-файли.

## Правила використання

1. Не змінюйте вихідні файли; очищені дані створюйте у власному проєкті.
2. Зберігайте атрибуцію і ліцензію кожного відкритого набору.
3. Перевіряйте слова перед показом користувачеві.
4. Матеріали зі статусом `REVIEW_REQUIRED` використовуйте відповідно до [політики даних](../docs/DATA_POLICY.md).
5. Для української зберігайте літери `і`, `ї`, `є`, `ґ` та нормалізуйте Unicode до NFC.

Докладні метадані наведені в [manifest.yml](manifest.yml). Цілісність файлів перевіряється командою `./scripts/verify-data.sh` у корені репозиторію.
